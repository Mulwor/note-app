<summary>Что такое словарь в Python?</summary>

Словарь в Python — это изменяемый, упорядоченный тип данных (порядок вставки сохраняется с Python 3.7), который хранит данные в виде пар «ключ → значение». Каждый ключ уникален, должен быть хешируемым и поддерживать сравнение через ==.

Словарь реализован через хеш-таблицу. Хеш-таблица — это структура памяти, где мы выделяем определённое пространство под записи. Когда мы обращаемся к ключу, мы берём его хеш, по хешу вычисляем номер ячейки в памяти и туда записываем значение. Если два ключа дают один и тот же индекс — это коллизия, тогда Python ищет следующую свободную ячейку и при поиске сравнивает ключи через ==. Когда таблица заполняется примерно на две трети, она расширяется, и элементы перераскладываются.

`Доп.вопрос`: Что может быть ключом в словаре?

Любой неизменяемый тип данных - int, float, bool, complex, строки, кортежи, bytes, none, frozenset (неизменяемое множество)

`Доп.вопрос`: Какая скорость у словаря при поиске, доступу к элементу, вставке или удаления элемента

При при поиске, доступу к элементу, вставке или удаления элемента: O(1), но если нам нужно прочитать из середины списка, то от O(N)

`Доп.вопрос`: Где быстрее поиск: в словарях или списках?

В словаре поиск по ключу быстрее — в среднем O(1), так как словарь реализован как хеш-таблица. В списке поиск значения занимает O(n).

```python
fruits = ["apple", "banana", "cherry", "date", "elderberry"]  # Список
prices = {"apple": 50, "banana": 30, "cherry": 120 } # Словарь
```

`Доп.вопрос`: Как получить список ключей из словаря?

Ответ: через list

```python
example = {
  'id': 7, 
  'name':'Shiba', 
  'color':'brown', 
  'speed':'very slow'
}

list(example)  # => ['id', 'name', 'color', 'speed']
```

`Доп.вопрос`: Как проверить, существует ли значение в списке?

Существует два способа - через `in`, который возвращает булевое значение и `index`, который возвращает индекс первого найденного значения, а если он не находит данное значение, то кидает исключения

```python
nums = [10, 20, 30, 40]

print(20 in nums)       # True
print(25 in nums)       # False
print(nums.index(30))   # 2
print(nums.index(99))   # ValueError: 99 is not in list
```

<summary>В чем разница между list (списком) и tuple (кортежем)?</summary>

- Список изменяемый, кортеж нет. 
- У списка длина может увеличивать, а у кортежа нет. 
- Кортежи более производительны и занимают меньше памяти, чем списки, так как у списков под запасом еще хранится память
- Кортеж - хешируемый, список нет
- Список имеет большое кол-во методов для изменения, у кортежа всего 2 - это index и count для подсчета вхождений.

Я бы использовал список, если данные наши будут обновляться, а кортеж бы использовал для тех данных которые написали один раз и больше бы не использовали
</details>

<summary>Что такое функция и как передается аргументы</summary>

Функция - кусок кода, который выполняет определенную задачу и который можно повторно использовать в других частях программы.

`Доп.вопрос`: Как передаются аргументы в функцию по ссылке или по значению

Все аргументы передаются по ссылка на объект, однако разделяются на изменяемые (list, dict, set) и неизменяемые объекты (int, str, tuple). Если мы изменим список, то он отразится и в оригинале (произойдет мутация), в то время как у неизменяемый отобразиться только внутри функции, снаружи мутация не произойдет

`Доп.вопрос`: Что такое *args и **kwargs? Можно ли написать *lol, **kek

Они нужно для того, чтобы функция могла принимать любое кол-во аргументов. Если мы исп *args, то они сгруппируются в кортеж, если в **kwargs, то в словарь. 

По поводу имен, мы можем написать любое главное помнить что args с 1 звездой, а kwargs с 2.

`Доп.вопрос`: Как передать необязательные или ключевые параметры из одной функции в другую?

В Python для передачи необязательных параметров в функцию используется синтаксис со знаком звездочки (*) и двойной звездочки (**). 

```python
def my_function(required_arg, *args, **kwargs):
    print(required_arg)
    if args:
        print(args)
    if kwargs:
        print(kwargs)

my_function('Hello, world!', 2, 3, 4, my_keyword='some_value')
```

`Доп.вопрос`: Почему пустой список нельзя исп как аргумент по умолчанию?

Мы не можем использовать список потому что это изменяемый тип и при каждом вызове этот тип будет изменяться. То есть мы не можем по умолчанию написать `my_list = None`, но мы можем исп доп.проверка:

```python
def my_function(my_list = None):
  if my_list is None:
    my_list = [];
    # do smth with my_list
    pass
```

<summary>- Что такое хвостовая рекурсия и почему нет оптимизации хвостовой рекурсии? Как это реализовать?</summary>

Хвостовая рекурсия - это когда функция вызывает сама себя в самом конце функции. 

В Python нет встроенной оптимизации хвостовых вызовов (TCO) по нескольким причинам: 

- Python не функциональный язык, и вместо хвост рекурсии он предлагает переписать на цикл, так как он проще, быстрее и в нем легче находить ошибки

- Во-вторых, TCO ломает трассировку стека: при ошибке было бы сложнее понять, как программа к ней пришла. 

Эмулировать хвостовую рекурсию можно через цикл

```python
def fibonacci(n)
  if n == 0: x = 0
  elif n == 1: x = 1
  # Пример хвостовой функции
  else: x = fibonacci(n - 1) + fibonacci (n - 2)
  return x

print(fibonacci(8)) # 21 (1.59 s)
```

- Обычный цикл for

```python
def fibonacci(n)
  cache = [0, 1]
  for n in range(2, n + 1):
    cache.append(cache[n - 1] + cache [n - 2])
  return cache[n]

print(fibonacci(8)) # 21 (1 ms)
```

<summary>Что такое декоратор и как написать свой?</summary>

Декоратор - это функция, которая принимает на вход другую функцию в качестве аргумента, расширяет функционал и не меняет исходный код. 

Кастомный декоратор
```python
def my_decorator(func):
  def wrapper():
    print('-- Перед вызовом --')
    func()
    print('-- После вызова --')
  return wrapper

@my_decorator
def say_hello():
  print('Hi')

say_hello()           # => Перед вызовом - Hi - После вызова

```

<summary>Что такое итератор и генератор</summary>

Итератор - это объект который по одному выдает элементы из какой-то последовательности. И у него есть 2 метода - __iter__ - возвращает сам итератор, и __next__ для вывода элементов по очереди. Когда элементы заканчиваются он возвращает исключения StopIteration

Генератор - особый вид итератора и создаётся c помощью функции def и yield. Он возвращает значения по одному, сохраняя своё состояние между вызовами next() и когда значения заканчиваются, он автоматически исключения StopIteration.


```python
def gen():
  yield 10
  yield "привет"
  yield [1, 2, 3]

g = gen()          # g — генератор
print(next(g))     # 10
print(next(g))     # привет
print(next(g))     # [1, 2, 3]
```

`Доп.вопрос`: Что такое yield

Yield возвращает значение, после чего сохраняет свое состояние и приостанавливает свое выполнение до след.вызова next(). В отличие от return, он не завершает функцию, а лишь ставит её на паузу.
</details>
