LLM (Large Language Model) — это нейросеть (нейронная сеть), обученная на больших объёмах текста, которая по запросу предсказывает продолжение текста.

RAG (Retrieval Augmented Generation) — подход, при котором перед ответом LLM в её контекст добавляется релевантная информация из внешнего источника, чтобы ответ был точнее и актуальнее.

RAG (Retrieval Augmented Generation) -  технология генерации текста с дополненным поиском, где retrieval — поиск релевантной информации во внешнем источнике: база знаний, документы, веб, API. Generation — добавление найденного в контекст LLM и генерация ответа.

Например: какой сейчас курс доллара? - LLM без доступа к актуальным данным не знает текущий курс. RAG-система сначала получает актуальный курс из внешнего источника, добавляет его в контекст, и затем LLM отвечает на основе этих данных.

RAG pipeline — это процесс, при котором по пользовательскому запросу сначала выполняется поиск релевантных документов из внешнего источника, затем эти документы добавляются в промпт, и на основе объединённого контекста генерируется итоговый ответ.

RAG = поиск + дополнение + генерация. Без поиска это обычный вызов LLM, а не RAG.
