0.  Как использовать глобальные переменные? Это хорошая идея?


1. Какой будет результат и почему

```python
  d1 = {1 : 1, 2 : 2, 3 : 3}
  d2 = d1
  d2[1] = 0
  print(d1)
  print(d2)
```

Ответ: У нас есть словарь d1. Потом создаём переменную d2 и присваиваем ей d1 — то есть d2 начинает ссылаться на тот же самый словарь в памяти. Потом d2[1] = 0 меняет значение по ключу 1 в этом общем словаре на 0. Поэтому print(d1) и print(d2) выведут одно и то же:

```python
{1: 0, 2: 2, 3: 3}
{1: 0, 2: 2, 3: 3}
```

Если бы мы сделали d2 = d1.copy() или d2 = dict(d1), то это была бы копия, и изменение d2 не затронуло бы d1.

5. Вывести словари, где значение ключа b > 150

```python
a = [
  { 'a': 140, 'b': 100 }, 
  { 'a': 10, 'b': 150 }, 
  { 'a': 15, 'b': 200 }
]
```

Ответ:

1. result = [element for element in a if element['b'] > 150]
  - первый element отвечает за что будет класть на каждой итерации
  - второй отвечает за то, что перебираем
2. result = list(filter(lambda d: d['b'] > 150, a))
3. Цикл

```python
result = []
for element in a:
  if element['b'] > 150:
    result.append(element)
```

6. Какой результат и почему

```python
l = [1, 2, 3]

def f(a, L = []):
  L.append(a)
  return L

f(4)            # L = [4]
f(5)            # L = [4, 5]

tmp_l = f(6)
print(tmp_l)    # L = [4, 5, 6]

f(7, l)         # L = [1, 2, 3, 7]
f(8, l)         # L = [1, 2, 3, 7, 8]
f(9, l)         # L = [1, 2, 3, 7, 8, 9]
print(l)          
```

В первом случае используется один и тот же список по умолчанию, который накапливает значения.
Во втором случае мы передаём явно список в функцию L ссылается на тот же объект, что и l, поэтому append меняет сам l.


7. Напишите декоратор, который будет перехватывать ошибки и повторять функцию максимум N раз.

```python
import functools

def retry(func):
  @functools.wraps(func)
  def wrapper(*args, **kwargs):
    max_retries = 3
    for i in range(max_retries):
      try:
        result = func(*args, **kwargs)
        return result
      except Exception as e:
        print(f'Error occureed: {e}. Retrying({i + 1 / max_retries})...')

    raise Exception(f'Function {func.__name__} failed after {max_retries} attempts.')
  return wrapper
```

9. Что будет напечатано в результате выполнения следующего кода?

```python
class Variable:
  def __init__(self, name, value):
    self._name = name
    self._value = value

  @property
  def value(self):
    print(self._name, 'GET', self._value)
    return self._value

  @value.setter
  def value(self, value):
    print(self._name, 'SET', self._value)
    self._value = value

var_1 = Variable('var_1', 'val_1')
var_2 = Variable('var_2', 'val_2')
var_1.value, var_2.value = var_2.value, var_1.value
```

- property - влияет на то, что при каждой инициализации name, value, то у нас будет отображаться  print(self._name, 'GET', self._value)
- @value.setter - при каждом переопределении, то у нас будет отображаться     print(self._name, 'SET', self._value)

Ответ:
var_2 GET val_2
var_1 GET val_1
var_1 SET val_1
var_2 SET val_2
