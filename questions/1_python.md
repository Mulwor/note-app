51. Что такое MRO? Как это работает?

MRO (Method resolution order) — это порядок, в котором Python ищет атрибуты и методы у класса и его предков. Он строится для каждого класса с помощью C3-линеаризации. При множественном наследовании MRO определяет, какой метод или атрибут будет найден первым, если он есть в нескольких базовых классах.

Как работает: Сам класс -> родители слева направо -> их родители -> ... -> object

```python
class O: ...
class A(O) ...
class B(O) ...
class C(O) ...
class D(O) ...
class E(O) ...
class K1(A, B, C) ...
class K2(B, D) ...
class K3(C, D, E) ...
class Z(K1, K2, K3)

print(*[c.__name__ for c in Z.mro()], sep=' -> ')
# (Z -> K1 -> A -> K2 -> B -> K3 -> C -> D -> E -> O -> object)

```

57. Что такое дескрипторы? Есть ли разница между дескриптором и декоратором?

Дескриптор работает с атрибутами класса и при доступе к атрибутам он переопределяет его поведения. Например: `__get__` - для чтения атрибута, `__set__`  - для записи, `__delete__` - для удаление. Например property, который может поддерживать чтение, запись и удаление атрибута.

Декоратор работает с функцией, мы оборачиваем какую-то функцию, метод класса и добавляем в него новый функционал 

```python
class Person:
  def __init__(self, name):
    self._name = name

  @property
  def name(self):
    print("property.__get__: читаем name")
    return self._name

  @name.setter # 
  def name(self, value):
    print("property.__set__: записываем name")
    self._name = value

  @name.deleter
  def name(self):
    print("property.__delete__: удаляем name")
    del self._name


p = Person("Alice")

print(p.name)      # сработает __get__
p.name = "Bob"     # сработает __set__
print(p.name)      # снова __get__
del p.name         # сработает __delete__
```

60. Что такое интернирование строк? Почему это есть в python?

Это когда одинаковые строки, ссылаются на один и тот же объект в памяти, и у него есть ограничение в 20 символов в ASCII. Это небольшая оптимизация в пайтоне, так как он экономит память и иногда ускоряет сравнения и поиск 

```python
a = 'hello'
b = 'hello'
print(a is b) 
# True, потому что обе переменные ссылаются на один и тот же объект в памяти

c = 'hello world'
d = 'hello world'
print(c is d) 
# False, потому что строка "hello world" длиннее 5 символов и содержит пробел а это не является интернированной

e = '_123'
f = '_123'
print(e is f) 
# True, потому что строка содержит только цифры и символ '_'
```

61. Как упаковать бинарные зависимости?

Существует 2 способа:

- Зафиксировать зависимости в файле:

Необходимо установить через pip/poetry зависимости. Затем мы можем создать файл requirements.txt и вручную перечислить зависимости: `request numpy pandas` и указать его версии. Wheel - это способ организовать все библиотеки в один зип-файл. Мы можем прописать `pip wheel -r requirements.txt` и у нас установится файл с разрешение .whl и установить все библиотеки не сложно через `pip install mypackage-1.0.0-py3-none-any.whl`

То есть можно собрать зависимости в какой-то файл, а можно собрать зависимости в один зип архив.

62. Почему в python нет оптимизации хвостовой рекурсии? Как это реализовать?

Хвостовая рекурсия - это когда функция вызывает сама себя в самом конце функции. 

В Python нет встроенной оптимизации хвостовых вызовов (TCO) по нескольким причинам: 

Во-первых, Python — не функциональный язык, поэтому вместо хвостовой рекурсии пайтон всегда предлагает написать обычный классический цикл. В Python цикл, как правило, проще, быстрее и не увеличивает глубину стека. 

Во-вторых, TCO ломает трассировку стека: при ошибке было бы сложнее понять, как программа к ней пришла. 

Эмулировать хвостовую рекурсию можно через цикл или паттерн «трамплин», но идиоматичнее просто переписать её в обычный цикл.

```python
def fibonacci(n)
  if n == 0: x = 0
  elif n == 1: x = 1
  # Пример хвостовой функции
  else: x = fibonacci(n - 1) + fibonacci (n - 2)
  return x

print(fibonacci(8)) # 21 (1.59 s)
```

- Обычный цикл for

```python
def fibonacci(n)
  cache = [0, 1]
  for n in range(2, n + 1):
    cache.append(cache[n - 1] + cache [n - 2])
  return cache[n]

print(fibonacci(8)) # 21 (1 ms)
```

78. Как передать необязательные или ключевые параметры из одной функции в другую?

В Python для передачи необязательных параметров в функцию используется синтаксис со знаком звездочки (*) и двойной звездочки (**). 

```python
def my_function(required_arg, *args, **kwargs):
    print(required_arg)
    if args:
        print(args)
    if kwargs:
        print(kwargs)

my_function('Hello, world!', 2, 3, 4, my_keyword='some_value')
```
