1. Что такое словарь (dictionary)? Что может быть ключом в словаре

Словарь в питоне реализован через хеш-таблицы. Хеш-таблица это такая структура памяти когда мы выделяем определенное пространство для каких-то записей в нашей памяти, соответственно когда мы обращаемся к какому-то ключу мы берем хеш этого ключа, затем берем остаток от деления хеша на кол-во ячеек, который мы выделили в памяти и соответственно получаем номер ячейки куда мы и записываем наш результат

И чтобы хеш от ключей не менялся ключи должны быть неизменяемыми типами данных

В качестве ключа может быть любой неизменяй тип данных

Итератор - это объект который имеет два метода это __iter__ и __next__. Метод __iter__ должен возвращать сам объект итератора, а метод __next__ должен возвращать следующее по счету значения 

Генератор особый вид итератора который не хранит все вычисляемую последовательность в виде списка, а вычисляет каждое след.значения при помощи какой-то формулы

26. Что означает self в классе?

Self ссылается на экземпляр класса. Так метод может обновлять объект, к которому принадлежит.

Ниже передача self в init() дает возможность установить цвет экземпляра при инициализации:

```python
class Shirt:
    def __init__(self, color):
        self.color = color
        
s = Shirt('yellow')
s.color
#=> 'yellow'
```
