01 - Какие виды JOIN ты знаешь? 

Существует две классификации join - это логические и физические:

Логические виды Join:

Left join - Берутся все данные из левой таблицы включая null и объединяются только те данные, которые есть еще и в правой таблицы. Те которые есть в левой таблицы но нет в правой таблицы. Колонка по правой таблицы будет null

- `LEFT JOIN` - Возвращает все данные из левой таблицы совпадающие строки из правой. Если совпадений нет, то 


Right join - Берутся все данные из правой таблицы и объединяются только те данные, которые есть еще и в левой таблицы. Те которые есть в правой таблицы но нет в левой таблицы. Колонка по левой таблицы будет null

Full join - Полное объединения левой и правой таблицы, где есть соединения - соединяться будут и левая и правая часть

Inner join - соединяем только пересечение

Self join - объединения таблицы само собой. Берете ключ идентификация + ключ еще одной идентификации и соединяете друг с другом. Например можем исп кто является начальник и узнать кто в подчинении у этого начальника

Cross join - каждую строку одной таблицы совмещаем с каждой строкой второй таблицы. На практике редко используется, но например можно использовать когда нужно было бы найти пару самых продаваемых вещей
