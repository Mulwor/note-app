<summary>Какой порядок выполнения у SQL запросов и что делает каждый метод</summary>

```sql
FROM (1) -> JOIN (2) -> WHERE (3) ->
GROUP BY (4) -> HAVING (5) -> SELECT (6) -> 
COUNT(*) OVER() (7 - окон.функции) -> QUALIFY(8) -> 
ORDER BY (9) -> LIMIT (10)`
```

`FROM` - Откуда достаем данные
* `JOIN` - ...
`WHERE` - Фильтрация данных до агрегации (группировки - GROUP BY)
`GROUP BY` - Группируем (объединяем данные) с одинаковыми значения в столбцы
`HAVING` - Фильтрация данных после агрегации (группировки - GROUP BY)
`SELECT` - Выбирать, достает поля из таблицы
* `OVER` - Оконные функции ...
* `QUALIFY` - Фильтрует результат работы оконных функций
`ORDER BY` - Сортирует по столбцам
`LIMIT` - Кол-во возвращаемых элементов

<summary>Какие типы данных бывают в postgreSQL</summary>

- `Числовые` - integer, bigint, numeric, double, smallint
- `Строковые` - varchar(n), char, text
- `Логические` - boolean
- `Дата / время` - timestamp, date, time, interval,
- `Остальные` - JSON, array, uuid, XML, cidr

`Доп.вопрос`: Чем отличается double от numeric? -
  - `numeric` - фиксированная точка
  - `double` - плавающая точка

`Доп.вопрос`: Чем отличаются varchar, char, text? - 
  - `varchar(n)` - это максимально допустимое кол-во символов. Например используется для валидации;
  - `char(n)` - это фиксированное длина значения. Если в char(5) вставить строку из 3 символов, например 'abc', то PostgreSQL дополнит её пробелами справа до 5 символов;
  - `text` - это просто текст;

`Доп.вопрос`: Для чего нужен `interval`? - чтобы к дате прибавить определенный промежуток времени - месяц, день, квартал и т.д.

`Доп.вопрос`: Что такое `UUID` - он позволяет создавать уникальный идентификатор

<summary>Какие есть виды команд SQL и для чего они нужны.</summary>

Команды SQL делятся на 5 основных групп по их назначению:

1. `DDL (Data Definition Language)` - команды, которые работают над объектами базы данных. К ним относятся таблицы, индексы и функции. Например через 
  - `CREATE` можем создать новый объект;
  - `ALTER` можем добавить или изменить колонку в таблице; 
  - `DROP` можем полностью удалить объект со всеми данными (таблицу);
  - `TRUNCATE` - удаляем данные, но оставляем структуру;

2. `DML (Data Manipulation Language)` - манипуляция внутри объектов: 
  - `INSERT` - вставка новой строки;
  - `UPDATE` - изменения существующей строки; 
  - `DELETE` - удаления строки по условию;

3. `DQL (Data Query Language)` -  это когда мы достаем какую-то выборку полей через `SELECT`

4. `DCL (Data Control Language)` - для управления правами доступа пользователей - добавляем, чтобы пользователь мог только читать, но не редактировать условно: 
  - `GRANT` - дать какое-то права, 
  - `REVOKE` - забрать права которое было дано 

5. `TCL (Transaction Control Language)` - команда для управления транзакциями:
  - `BEGIN / START TRANSACTION` — запускает новую транзакцию;
  - `COMMIT` - сохраняет все изменения;
  - `ROLLBACK` - откатить текущие изменения;
  - `SAVEPOINT` - контрольная точка на которую можно откатиться;

03. Отличие DROP, DELETE, TRUNCATE .

- `DROP` - удаляет полностью всю таблицу
- `DELETE` - удаляет строки по условию из таблицу
- `TRUNCATE`  - полностью очищает таблицу, но сама таблица остается
