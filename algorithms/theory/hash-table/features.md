Map

`map.set(num, (map.get(num) || 0) + 1)` - Нужен для подсчёта количества вхождений элементов с использованием Map

1. `map.get(num)` - Получаем из Map значение, которое хранится по ключу num.
2. `map.get(num) || 0` - Если значение есть то оно берет его, в противном случае возвращает число 0
3. `+ 1` - После этого увеличиваем число на единицу
4. `map.set(num, ...)` - Записывает новое значение обратно в Map

Например - map.set(num, (map.get(num) || 0) + 1); - Увеличь счётчик для num на 1. Если num встречается впервые — установи счётчик равным 1

```js
const numbers = [5, 2, 5, 5, 2];
const map = new Map();

for (const num of numbers) {
  map.set(num, (map.get(num) || 0) + 1);
}

num = 5 → Map: {5 → 1}
num = 2 → Map: {5 → 1, 2 → 1}
num = 5 → Map: {5 → 2, 2 → 1}
num = 5 → Map: {5 → 3, 2 → 1}
num = 2 → Map: {5 → 3, 2 → 2}

5 встречается 3 раза
2 встречается 2 раза
```

```js
map.set(
  num,                    // какой элемент считаем
  (map.get(num) || 0) + 1 // сколько было + 1
);
```
