<summary> Что такое pickle?</summary>

pickle - это модуль, который превращает объект в байтовый поток и потом возвращает обратно в объект, но у него есть проблемы с безопасностью и мы можем случайно загрузить вредоносный код через pickle.load() - а более безопасный вариант для обмена данными это json

```.py
import pickle

# Сериализация (упаковка)
data = {"name": "Alice", "age": 30}
with open("file.pkl", "wb") as f:
    pickle.dump(data, f)

# Десериализация (распаковка)
with open("file.pkl", "rb") as f:
    loaded = pickle.load(f)
    print(loaded)  # {'name': 'Alice', 'age': 30}
```

<summary>Чем отличаются многопоточное и многопроцессное приложение?</summary>


В рамках одного процесса программы имеют доступ к одной и той же памяти к одним и тем же ресурса просто в разных потоках - многопоточность. Многопоточность выполняет за счет библиотеки treading

А в многопроцессорных системах каждое приложения имеет доступ к своей памяти и своим ресурсам. Многопроцесорность достигается при помощи библиотек multiprocessing и concurrent.future

</details>

<summary>Зачем нужен pdb?</summary>


pdb - интерактивный отладчик кода, которая вызывается в командной строке. С помощью него мы можем проходить по командной строки, , посмотреть значения переменных, и пытаться найти ошибки.

```python
import pdb

def divide(a, b):
  pdb.set_trace()
  return a / b

divide(10, 0)
```
