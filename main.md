<summary> Что такое pickle?</summary>

pickle - это модуль, который превращает объект в байтовый поток и потом возвращает обратно в объект, но у него есть проблемы с безопасностью и мы можем случайно загрузить вредоносный код через pickle.load() - а более безопасный вариант для обмена данными это json

```.py
import pickle

# Сериализация (упаковка)
data = {"name": "Alice", "age": 30}
with open("file.pkl", "wb") as f:
    pickle.dump(data, f)

# Десериализация (распаковка)
with open("file.pkl", "rb") as f:
    loaded = pickle.load(f)
    print(loaded)  # {'name': 'Alice', 'age': 30}
```

<summary>Что такое декоратор и как написать свой?</summary>

Декоратор - это функция, которая принимает на вход другую функцию в качестве аргумента, расширяет функционально и не меняет исходный код. 

Кастомный декоратор
```python
def my_decorator(func):
  def wrapper():
    print('-- Перед вызовом --')
    func()
    print('-- После вызова --')
  return wrapper

@my_decorator
def say_hello():
  print('Hi')

say_hello()           # => Перед вызовом - Hi - После вызова

```

Например мы можем создать отдельный декоратор для логгирование, для проверки прав.

<summary>Что такое итератор и генератор</summary>


Итератор - это объект который по одному выдает элементы из какой-то последовательности. И у него есть 2 метода - __iter__ - возвращает сам итератор, и __next__ для вывода элементов по очереди. Когда элементы заканчиваются он возвращает исключения StopIteration

Генератор - особый вид итератора и создаётся c помощью функции def и yield. Он возвращает значения по одному, сохраняя своё состояние между вызовами next() и когда значения заканчиваются, он автоматически исключения StopIteration.


```python
def gen():
  yield 10
  yield "привет"
  yield [1, 2, 3]

g = gen()          # g — генератор
print(next(g))     # 10
print(next(g))     # привет
print(next(g))     # [1, 2, 3]
```
</details>

<summary> Для чего в классе используется атрибут __slots__?</summary>

C помощью slots мы указываем список атрибутов, которые разрешены у экземпляров класса и с которыми мы реально будем работать. Например у нас есть атрибуты с name и age и если они есть в слоте, то они будут определяться для каждого экземпляра. Таким образом мы фиксируем, что каждый экземпляр будет содержать только эти 2 атрибута name и age

```python
class Person:
    __slots__ = ('name', 'age')

    def __init__(self, name, age):
        self.name = name
        self.age = age

p = Person('Anna', 30)
print(p.name, p.age)  # Anna 30

p.city = 'Moscow'
# AttributeError: 'Person' object has no attribute 'city'
```

</details>

<summary>Что такое метаклассы и в каких случаях их следует использовать?</summary>

Метаклассы — это классы, экземплярами которых являются другие классы. По умолчанию это type. Они позволяют управлять созданием и поведением классов: добавлять или менять атрибуты и методы, влиять на создание экземпляров. 

```python
class Meta(type):
  def __new__(mcls, name, bases, namespace):
    # добавляем атрибут в пространство имён класса
    namespace["created_by"] = "Meta"
    return super().__new__(mcls, name, bases, namespace)


class A(metaclass = Meta):
  pass

print(A.created_by)        # Meta
print(type(A))             # <class '__main__.Meta'>
print(A().created_by)      # AttributeError — экземпляр не видит атрибут метакласса
```
</details>

<summary>Какие проблемы есть в python?</summary>

Он медленнее многих языков - Go, C, C++, Rust из-за динамической типизации (ошибки типов всплывают только в рантайме) и GIL, которая мешает именно CPU-bound многопоточности. Также отступы как синтаксис — не всегда удобно для новичков и при перенесение каких-то модулей с одного языка на другой. А также высокое потребление памяти — объекты в Python «тяжёлые»: у каждого есть счётчик ссылок, заголовок, часто __dict__, поэтому на больших объёмах данных Python проигрывает
