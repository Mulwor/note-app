Подзапрос -  это запрос, который вложен внутрь другого (основного или внешнего) запроса. Чаще всего используется в секции фильтрации (WHERE), но может использоваться и в SELECT, FROM и HAVING. Подзапрос нужен для фильтрации, расчетов или объединения данных и стоит помнить, что внутри одного подзапроса может быть несколько

Задача: найти самый дешевый товар в магазине:

```sql
SELECT price, product_id, name 
FROM products
ORDER BY price
LIMIT 1
```

Задача - выполнено, а что если категория с данным товаром может быть больше 1 - условно у нас есть огурцы и помидоры по 1 руб и выведется либо одно либо второе. 

Возникает вопрос - а как сделать, так, чтобы вывести все минимальные значения. И тут как раз помогает нам подзапросы

```sql
SELECT price, product_id, name 
FROM products
WHERE price = (SELECT min(price) FROM products)
```

Другая задач - у нас есть пользователь с id 500 и он постоянно жалуется на курьера, который доставляет заказы. Необходимо найти всех курьеров, которые доставляли му заказ

Находим человек с id 500
`SELECT order_id FROM user_actions WHERE user_id = 500`
Курьер у нас находится в другой таблице и мы можем написать
`SELECT courier_id FROM courier_actions WHERE action='deliver_order'`

Но возникает вопрос - как объединить эти 2 запроса. Мы просто берем курьера, который доставлял пользователю товар

```sql
SELECT courier_id 
FROM courier_actions
WHERE action = 'deliver_order' AND 
  order_id IN (SELECT order_id FROM user_actions WHERE user_id = 500)
```
