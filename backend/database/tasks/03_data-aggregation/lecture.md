Функция `array_length(array, integer)` возвращает длину указанного (одного) массива, 
- anyArray - массив любого типа; 
- integer - номер измерения, длину которого нужно узнать (нач с 1). Грубо говоря если у нас внутри много массивов [1,2],[3,2]. При указании 1 он будет считать внутренности - [1,2], а если 2, то [3,4]

Функция AGE возвращает разницу между двумя значениями, представленными в формате TIMESTAMP. При этом из первого значения вычитается второе, а сама разница получается в формате INTERVAL:

```sql
SELECT AGE('2022-12-12', '2021-11-10')  => 397 days, 0:00:00
SELECT AGE(TIMESTAMP '2021-11-10')      => 397 days, 0:00:00 - тек.время
SELECT AGE(current_date, '2021-11-10')  => 397 days, 0:00:00 - тек.время
SELECT AGE(current_date, '2021-11-10')::VARCHAR  => 1 year 1 mon 2 days
```
